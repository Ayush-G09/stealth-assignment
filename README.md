# Agent Activity Explorer

Frontend take-home assignment. **Read [ASSIGNMENT.md](ASSIGNMENT.md) first**: it has the full brief, the API reference and how to submit.

```bash
npm install
npm run api            # mock API on http://localhost:4000
npm run perf-clinic    # Part B page on http://localhost:5174
```

| Path | What it is |
|---|---|
| `app/` | Your Part A app goes here (React with Vite, or Next.js) |
| `perf-clinic/` | Part B: the page to diagnose and fix |
| `bin/` | Prebuilt mock API binaries; `npm run api` picks the right one |
| `scripts/` | Launchers for the two commands above |
